# План розробки курсового проєкту: Restaurant Web App

## 1. Загальний опис проєкту
Веб-застосунок для ресторану, що надає користувачам можливість ознайомитися з меню, прочитати відгуки та забронювати столик онлайн.

---

## 2. Статус реалізації функціоналу

###  Реалізовано (Лабораторна робота 1.1)
* **Архітектура проєкту:** Налаштовано React-застосунок на базі Vite та клієнтський роутинг (`react-router-dom`).
* **Головна сторінка (`/`):** Інформація про ресторан, вітальний блок та швидка навігація.
* **Сторінка меню (`/menu`):** Відображення списку страв із картками категорій, цінами та описами із локального джерела даних.
* **Форма бронювання (`/booking`):** Інтерактивна форма запису з керуванням станом (`useState`), валідацією вхідних даних та обробкою відправки.
* **Сторінка відгуків (`/reviews`):** Список відгуків відвідувачів.
* **Контейнеризація:** Підготовлено `Dockerfile` (на базі Node 22) та `docker-compose.yml` для ізольованого запуску додатка.

### Заплановано (Майбутні етапи розробки)
* **Інтеграція REST API:** Підключення бекенд-сервера (Node.js/Express) для динамічного завантаження меню та обробки запитів.
* **База даних:** Збереження даних про бронювання столиків та нові відгуки у БД (PostgreSQL/MongoDB).
* **Фільтрація та пошук:** Додавання фільтрів за категоріями страв (вегетаріанське, напої, десерти) та пошуку за назвою.
* **Авторизація:** Особистий кабінет користувача для перегляду історії своїх бронювань.
